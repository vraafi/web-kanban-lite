# Kanban Lite

Papan kanban 3 kolom tanpa library: tambah/geser/hapus kartu, tersimpan di localStorage, mendukung papan ketik.

## Isi

- `index.html`
- `app.js`
- `style.css`

## Cara pakai

Buka `index.html` langsung di browser — tidak perlu server, tidak perlu build, tidak ada data yang dikirim ke mana pun.

## Bukti mutu

Diperiksa otomatis dengan QC tiga lapis (kode, visual, pengguna) sebelum
diterbitkan. Vonis: **terima**.

- **kode** — lulus
- **visual** — lulus
- **pengguna** — lulus

Berkas mentah hasil pemeriksaan ada di `qc.json` pada repo ini.

## Berkas pendukung

- `PORTOFOLIO.md` — ringkasan produk untuk portofolio
- `RESUME-BULLETS.md` — butir resume
- `LINKEDIN.md` — draf pengumuman
